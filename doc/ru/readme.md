YaMusic Helper (Загрузчик Яндекс Музыки)

Ищите и скачивайте свои любимые треки, альбомы и плейлисты из Яндекс Музыки
напрямую через NVDA.

Возможности:
1. Поиск треков, альбомов, артистов и плейлистов.
2. Мгновенное прослушивание треков (в плеере) без предварительного скачивания (Ctrl+P).
3. Скачивание в высоком качестве MP3 (до 320 kbps).
4. Быстрый доступ к понравившимся трекам и плейлистам.
5. Поддержка выделения нескольких элементов для скачивания треков одновременно.

Полное руководство по получению токена и настройке:
1. Откройте меню NVDA (NVDA+N).
2. Перейдите в Параметры -> Настройки -> Настройки Яндекс Музыки.
3. Нажмите кнопку "Получить Токен (Открыть браузер)".
4. На экране появится специальный код подтверждения, который автоматически
   скопируется в буфер обмена. После закрытия сообщения откроется ваш
   браузер по умолчанию.
5. Войдите в свой аккаунт Яндекса в браузере (если еще не вошли).
6. Вставьте скопированный код (Ctrl+V) на открывшейся странице и подтвердите.
7. Вернитесь в NVDA. На экране появится сообщение "Токен успешно получен
   и введен!".
8. (Необязательно) В поле "Плеер" вы можете вписать название вашего любимого плеера (например, aimp.exe или vlc.exe) для прослушивания треков.
   Вы также можете нажать кнопку "Обзор...", чтобы выбрать .exe файл плеера вручную.
9. Нажмите кнопку OK для сохранения настроек.

Использование:
Нажмите NVDA+Shift+Y для открытия диалога Загрузчика Яндекс Музыки.
Введите название песни или артиста в поле поиска и нажмите Enter.
Для прослушивания любого трека в списке нажмите Ctrl+P.
Выберите элементы из списка, используйте Пробел (Space) для их отметки,
затем нажмите клавишу Контекстного меню (Applications) и выберите "Скачать".
Также можно нажать Enter для просмотра содержимого артиста или альбома.
